# All Labs 🔬

**Live Production Link:** [https://skip-the-journal.vercel.app](https://skip-the-journal.vercel.app)

## 📖 The Problem

As MCA students, we are required to write all our labs in our generals (journals). It was always a huge pain to write them all by ourselves. The manual effort consumed a significant amount of time, meaning we wouldn't get enough time for actual coding. Furthermore, trying to find these lab materials from someone else was incredibly hectic.

## 💡 The Solution

**All Labs** was built to solve this exact problem. This project serves as a centralized platform where all the lab materials and resources will be readily available for all students. 

## ✨ Core Platform Benefits

Writing journals manually is a repetitive task. Our curated archive saves time, allowing MCA students to focus on solving software engineering problems, debugging scripts, and preparing portfolios.

- **Unified Lab Material Registry**
  Every single lab session is fully available inside this platform. There is no need to invest valuable hours doing endless Google search runs or tracing old archives.

- **No More Academic Fumbling**
  Eliminate the effort of spending hours figuring out the entire complex database configuration or compiler steps by yourself.

- **Maximize Actual Coding Hours**
  Saves endless mechanical journal writing hours so you can focus 100% of your energy on actual practical software development, real coding, and deep learning.

- **Better First Semester for Juniors**
  As MCA first-semester students, I worked to ensure future juniors won't face the same challenges I did.

## 🚀 Tech Stack

This project is built using a modern and robust tech stack:

- **Framework:** [Next.js](https://nextjs.org/) 16
- **Styling & UI:** [Tailwind CSS](https://tailwindcss.com/), [Radix UI](https://www.radix-ui.com/) & [Framer Motion](https://www.framer.com/motion/)
- **Authentication:** [Clerk](https://clerk.dev/)
- **Database ORM:** [Drizzle ORM](https://orm.drizzle.team/)
- **Data Fetching:** [tRPC](https://trpc.io/) & [React Query](https://tanstack.com/query/latest)
- **Uploads:** [UploadThing](https://uploadthing.com/)
- **Data Seeding** [Gemini API](https://ai.google.dev/gemini-api/docs)

## 🛠️ Getting Started

First, install the dependencies. The project uses `bun`.

```bash
bun install
```

Then, run the development server:

```bash
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.
